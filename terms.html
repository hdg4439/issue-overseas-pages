1. 프로그램의 용도

이슈_해외반응은 채널 운영자가 본인의 PC와 본인의 계정을 연결해 사용하는 개인용 뉴스 정리·영상 제작 도구입니다. 일반 방문자에게 계정 가입이나 공개형 영상 제작 서비스를 제공하지 않습니다.

2. 연결과 게시

사용자는 본인이 관리할 권한을 가진 채널만 연결합니다. Telegram에서 항목을 선택하고 제작·자동 공개를 실행하면, 프로그램은 해당 항목을 영상으로 만들고 검수 후 연결된 채널에 게시합니다. 제작 중에는 일시정지·취소 기능을 사용할 수 있습니다. 이미 완료된 공개는 YouTube Studio에서 관리합니다.

3. 자료와 음악

영상은 출처를 확인한 기사와 자체 작성한 한국어 설명으로 구성합니다. 사용자 음악이나 기타 자산을 추가할 때는 해당 자산의 이용 조건과 필요한 출처 표시를 적용합니다. 확인되지 않은 사실과 실제 발언이 아닌 내용을 사실처럼 게시하는 용도로 사용하지 않습니다.

4. YouTube 및 외부 서비스

이 프로그램은 YouTube API Services를 이용하며, 프로그램을 이용하는 사용자는 YouTube 서비스 약관에도 동의합니다. Google·Telegram·DeepSeek 등 연결 서비스에는 각 서비스의 이용 조건과 사용량 제한이 적용됩니다. DeepSeek 사용 요금과 사용자가 선택한 외부 자산·서비스 비용은 각 공급자의 요금에 따릅니다.

5. 데이터와 이용 중단

정보의 사용·보관·연결 해제·삭제 절차는 개인정보처리방침에 설명합니다. 사용자는 자동 실행을 중지하고 Google 계정에서 접근 권한을 철회해 연동을 종료할 수 있습니다. 이미 게시된 영상과 전송된 메시지는 해당 서비스에서 별도로 관리합니다.

6. 변경 안내

기능과 운영 조건이 바뀌면 이 페이지를 갱신하고 문서 기준일을 변경합니다.
