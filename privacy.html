개인정보처리방침

문서 기준일: 2026년 10월 29일 · 적용 대상: 이슈_해외반응 개인용 Windows 프로그램과 안내 사이트

1. 운영자와 처리 목적

운영자는 이슈_해외반응 채널 운영자입니다. 프로그램은 운영자가 선택한 해외 보도를 영상으로 제작해 본인의 YouTube 채널에 게시하기 위해 정보를 처리합니다.

2. 처리하는 정보

  • Google OAuth 접근·갱신 토큰, 연결된 YouTube 채널 ID와 채널명.
  • 프로그램이 업로드한 영상의 ID·처리 상태·공개 상태, 업로드 세션과 작업 기록.
  • Telegram 봇 토큰, 허용된 수신 계정·채팅 ID, 제작 항목 선택과 제어 명령.
  • 공개 뉴스 원문·출처, 생성 대본·영상·자막·음악 및 검수 결과.

Google 비밀번호는 프로그램에서 수집하지 않습니다. Google 승인 화면의 요청 범위는 youtube.force-ssl이며, 현재 구현은 채널 확인·영상 업로드·게시 상태 조회 및 변경에 사용합니다. 댓글·평가·구독자 목록을 수집하는 기능은 구현하지 않았습니다.

3. 저장과 보관

인증 토큰과 API 키는 Windows DPAPI로 암호화해 운영자 PC에 저장합니다. 뉴스·영상 파일, 계정 식별자와 작업 기록은 같은 PC의 설정 파일·작업 폴더·SQLite 데이터베이스에 저장합니다. 현재 구현에는 이 자료를 일정 기간 후 자동 삭제하는 기능이 없으며, 운영자가 로컬 자료를 직접 관리합니다. 안내 사이트의 공개 파일에는 인증 토큰과 작업 데이터가 포함되지 않습니다.

4. 서비스 간 전달

YouTube에는 선택한 영상과 게시 메타데이터를 전송합니다. Telegram에는 운영자의 브리핑과 제작 결과·영상 링크를 전송합니다. DeepSeek에는 공개 기사와 분석·대본 검수 요청을 전달합니다. Google 인증 토큰과 Google API로 조회한 계정 정보는 DeepSeek에 전달하지 않습니다. Google 사용자 데이터를 판매하거나 광고 타기팅 또는 AI 모델 학습에 사용하지 않습니다.

5. 연결 해제와 삭제

운영자는 먼저 프로그램의 자동 실행을 비활성화하고 제작·공개를 일시정지할 수 있습니다. Google 계정의 연결 관리에서 이 앱의 접근 권한을 철회할 수 있습니다. 철회는 PC에 저장된 파일을 삭제하지 않습니다.

로컬 자료 전체를 삭제하려면 실행기와 설정 창을 종료한 뒤 운영자 PC의 프로그램 폴더에서 data 폴더와 config.json을 삭제합니다. 이 작업에는 다른 연동 키와 제작 결과도 포함됩니다. 별도로 만든 백업·복사본은 해당 위치에서 삭제합니다. 이미 게시한 영상은 YouTube Studio에서, Telegram 메시지는 해당 대화에서 별도로 삭제할 수 있습니다.

6. 안내 사이트 방문 정보

이 안내 사이트 자체에는 회원가입·분석 스크립트·광고·쿠키 저장 기능이 없습니다. GitHub Pages에 게시되는 경우 호스팅 사업자인 GitHub가 보안 목적으로 방문자의 IP 주소를 처리합니다. 자세한 내용은 GitHub 개인정보처리방침을 확인할 수 있습니다.

7. 외부 서비스와 변경 안내

이 프로그램은 YouTube API Services를 이용합니다. Google·YouTube의 정보 처리에는 Google 개인정보처리방침이 적용됩니다. 정보 처리 방식이 변경되면 이 페이지의 문서 기준일과 내용을 갱신합니다.
