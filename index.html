PROGRAM INFORMATION

해외 언론의 한국 보도를
읽고, 고르고, 영상으로.

이슈_해외반응은 채널 운영자가 자신의 Windows PC에서 사용하는 뉴스 정리·영상 제작 도구입니다. 해외 언론의 한국 관련 보도를 확인하고, 운영자가 선택한 항목만 주제 이미지·한국어 내레이션·자막·배경음악 영상으로 제작합니다.

01 / 수집최근 24시간의 해외 보도매일 바르샤바 오전 8시 기준으로 스포츠·연예·경제·사회를 정리합니다.
02 / 선택Telegram에서 항목 선택번호가 있는 브리핑에서 운영자가 제작할 내용을 선택합니다.
03 / 제작이미지와 내레이션으로 구성원문과 대본을 검수하고 연결된 채널에 업로드·공개합니다.

YouTube 연결을 사용하는 이유

이 프로그램은 YouTube API Services를 이용합니다. Google 로그인 승인 후 대상 채널을 확인하고, 선택한 항목의 영상과 제목·설명을 업로드하며 처리 결과와 공개 상태를 조회합니다. 운영자가 제작·자동 공개를 실행하면 검수를 통과한 영상은 추가 승인 없이 공개됩니다.

Google 로그인은 PC 프로그램에서 진행합니다. 이 안내 사이트는 로그인 기능이나 비밀번호 입력란을 제공하지 않습니다. 프로그램은 채널 운영자 본인의 계정을 위한 개인용 도구이며, 일반 방문자의 YouTube 계정 연결을 받지 않습니다.

계정 정보와 사용자의 제어

Google 인증 토큰은 현재 Windows 계정에 묶인 암호화 저장소에 보관합니다. 설정 창과 Telegram 명령으로 제작을 일시정지할 수 있으며, Google 계정에서 앱의 접근 권한을 철회할 수 있습니다. 처리 정보와 삭제 절차는 개인정보처리방침, 이용 조건은 이용약관에 설명합니다.
